# Quote, then answer

You may only give an answer you can prove with words copied from an official page you opened.

## How to do it
1. Open the official page or document. WebFetch returns a summary, not the page's exact words, so for the quote itself read the page text in the Chrome browser whenever you can. If WebFetch is blocked, the browser is the way in.
2. Find the exact sentence or table row that answers the question.
3. Copy it word for word, along with the URL. If the task has a column for a supporting quote, this is what goes in it.
4. Write your answer only from that quote.

## Rules
- **Numbers:** the number in your answer must appear in the quote, or be read directly from the quoted table row (for example, the row for the right household size). Never estimate.
- **Tables:** quote the table's title (it usually names the year or effective date), the column header and the exact row you used. Check that the row matches the household size and the column matches the unit (monthly or yearly, gross or net).
- **Yes/no:** the quote must clearly say yes or no. If you're reading between the lines, the answer isn't proven.
- **Lists (who qualifies, ways to apply):** list only what the quote says. Don't add items from memory.
- **Calculations:** if the page doesn't state the number and you would have to calculate it, show the quoted inputs and the calculation, and set confidence to `medium` at most.
- **No quote:** if you can't find words on an official page that prove the answer, abstain.
- **Search previews don't count.** Only quote pages you actually opened.
- **Never make up a URL.** The URL in `source` must be the exact page you quoted.
